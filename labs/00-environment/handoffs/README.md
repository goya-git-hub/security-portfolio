# Weekly handoffs

A handoff is a short note written every Friday for the next person who picks up the work, including future me. It says what was finished, what is still open, what to watch out for, and what is needed to keep going.

## Format

Name each file by the Friday it is written, as `YYYY-MM-DD.md`. Each file has a date heading and exactly four labelled lines:

```
# Week of <Monday's date>

- Done: what was finished and verified this week.
- Open: what is started or next, still to finish.
- Watch: a risk, trap, or lesson the next person should know.
- Need: anything blocking, or "nothing blocking".
```

## Rule: these files are public

This repository is public. A handoff never contains secrets, account locations, recovery details, private identities, or personal data. Describe the work, not the accounts behind it.
